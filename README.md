### Projects

♠️ [Røkkjar](https://rokkjar.no)
>  Røkkjar is a lesser known Nordic card game, especially popular in Stryn, Norway. After my brother played at the yearly christmas tournament, we realized no online version exists, so if you want to practice you had to play in-person. Over the new years we created Røkkjar online. I mostly did the frontend, REST API, rating-system and auth while my brother did most of the game logic. The tech stack features Vite, React, TypeScript, Tanstack Router, tRPC, and Postgres.  

📚 [WikiBot](https://wikibot.gg)
>  My first major, public project. WikiBot is a discord bot for looking up wiki articles within discord. Returns nicely formatted embeds with pictures, support for hypertext and "scrolling". Can look up on Wikipedia, all fandom.com wikis and with premium you can add any wikimedia-driven wiki. Written in TypeScript and as of writing has been added to 1800+ servers, however I have not been actively updating nor promoting WikiBot for a while

🎯 [Arraz](https://arraz.app)
> An open-source darts scorecounter. Play the most popular games, such as X01, Cricket, Killer & more. No bloat, no login needed. Also includes some guides and a rulebook.
